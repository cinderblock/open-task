## Findings / gotchas

- **PawnIO is installed and running on this machine** (`C:\Program Files\PawnIO`:
  `PawnIOLib.dll`, `PawnIOLib.h`, `PawnIOUtil.exe`; service `PawnIO` is a running
  kernel driver). Its C API: `pawnio_open(&handle)`, `pawnio_load(handle, blob, size)`,
  `pawnio_execute(handle, "name", in: *const u64, in_count, out: *mut u64, out_count,
  &returned)`. Modules are signed `.bin` blobs from `namazso/PawnIO.Modules`
  (IntelMSR, AMDFamily17, RyzenSMU, LpcIO); LibreHardwareMonitor 0.9.6 reads MSRs this
  way and needs PawnIO installed separately. Module function names and licence: see
  the next entry once fetched.
