- **PawnIO is installed and running on this machine** (`C:\Program Files\PawnIO`:
  `PawnIOLib.dll`, `PawnIOLib.h`, `PawnIOUtil.exe`; service `PawnIO` is a running

## Findings, continued

- **The machine-wide cargo config shares one intermediate build directory across
  every project and worktree** (`~/.cargo/config.toml`, `build.build-dir`, added
  2026-10-02). Workspace members hash the same in every worktree, so three agents
  building at once overwrite each other's rlibs and the main tree's final binary can
  be linked from a mix (an exe with my `ot-ui` and an agent's `ot-shell-win`). For
  anything that must be trusted (screenshots, release builds) use a private
  directory: `export CARGO_BUILD_BUILD_DIR="$PWD/target/build-main"` (first build
  ~5 min; 525 MB). The repo's `target/` only holds final artifacts.
- **Another session moved master** (v0.8.0, the chart span work) while this thread
  worked uncommitted in the same checkout; `git log` before assuming the base.
